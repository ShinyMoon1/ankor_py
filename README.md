# Анкор: учет заказов

Внутренняя информационная система ООО «Анкор» (оптовая торговля
табачными изделиями и продуктами питания) для учета заявок розничных
точек, складских остатков и статусов заказов. Учебный проект для
производственной практики ПП.02 «Ревьюирование программных модулей».

## Технологии

- Python 3.12, Flask — серверная часть
- HTML5, CSS3, JavaScript — веб-интерфейс
- SQLite — хранение данных тестового контура
- pytest — модульные тесты
- Pylint, Flake8, Black — статический анализ Python
- ESLint, StyleLint — анализ JavaScript и CSS

## Структура проекта

- `order.py` — класс `Order`: позиции, расчет стоимости, скидки, статусы
- `app.py` — маршруты Flask, формы заказа
- `templates/` — HTML-шаблоны страниц
- `static/` — стили CSS и сценарии JavaScript
- `test_orders.py` — тесты pytest

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Приложение доступно по адресу `http://127.0.0.1:5000`.

## Тесты

```bash
pytest -v
```
